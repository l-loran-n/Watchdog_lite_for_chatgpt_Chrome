# Watchdog Lite for ChatGPT — Chrome

**Версия:** 6.3.7 (security-hardened) · **Браузер:** Google Chrome 120+ · **Платформа:** Windows, macOS, Linux

Watchdog Lite — автономное расширение Chrome (Manifest V3), которое сопровождает **выбранные пользователем** диалоги ChatGPT. Оно отправляет техническую команду продолжения, анализирует ответ и прекращает сопровождение при статусе `PASS` или `FAIL`.

Ни сервер, ни Telegram-бот, ни Desktop Commander, ни API-ключ OpenAI для этой редакции **не требуются**. Нужны работающий Chrome, доступ к сайту ChatGPT и вход в свою учётную запись.

> **Важное предупреждение:** расширение автоматически отправляет сообщения **от вашего имени**. Оно не способно гарантировать, что ChatGPT не повторит уже выполненное действие. **Не используйте его без присмотра** для переводов денег, оплаты, удаления файлов, изменения инфраструктуры, размещения секретов, отправки писем или других действий с необратимыми последствиями.

## Возможности

- Несколько независимых диалогов, каждый с собственным `COMMAND_ID`, состоянием и ограничениями.
- Статусы `WORKING` → продолжение, `PASS`/`FAIL` → остановка.
- Ограниченная попытка восстановить ответ после ошибки ChatGPT (не более двух `RESCUE` за соответствующий цикл ошибки).
- Защита пользовательского текста в редакторе: пока поле занято, Watchdog не отправляет команду.
- До **100 автоматических сообщений** за один запуск диалога; до **20 одновременно отслеживаемых** диалогов.
- Остановка отдельного диалога или всех диалогов одной кнопкой.
- Нет встроенных сетевых обращений к сторонним серверам; нет аналитики или телеметрии проекта.

## Быстрый старт

1. Откройте этот репозиторий на GitHub. Нажмите **Code → Download ZIP** либо клонируйте его через Git.
2. Распакуйте архив, например в `Documents/Watchdog-Lite`. Выберите папку, **непосредственно содержащую `manifest.json`**. Не запускайте файлы двойным кликом.
3. Откройте в Chrome адрес `chrome://extensions`.
4. В правом верхнем углу включите **Режим разработчика** (*Developer mode*).
5. Нажмите **Загрузить распакованное расширение** (*Load unpacked*) и укажите эту папку.
6. Убедитесь, что карточка **Watchdog Lite — ChatGPT** включена, а ошибок загрузки нет.
7. Перезагрузите вкладки `chatgpt.com`, открытые до установки. При необходимости закрепите расширение через меню пазла Chrome.
8. Откройте **существующий диалог** ChatGPT, дождитесь окончания генерации и отсутствия своего черновика в поле ввода.
9. Нажмите на иконку Watchdog и кнопку **«Добавить текущий диалог»**. Появится карточка со статусом.
10. Для другого диалога перейдите в его вкладку и повторите шаг 9.

Расширение поддерживает обычные чаты `https://chatgpt.com/c/...`, а также чаты внутри GPT/Projects с путём `/g/.../c/...`. Для ссылки вида `/g/g-...` без идентификатора чата выполняется дополнительная проверка истории после первого перехода. Домашняя страница `https://chatgpt.com/` не является диалогом и не подходит для добавления.

**Не включайте одновременно старую и новую сборки Watchdog для одного диалога:** они способны посылать конкурирующие сообщения. Перед переключением остановите диалоги в старом расширении и отключите его на `chrome://extensions`.

## Использование

После добавления конкретного чата Watchdog проверяет, свободно ли поле ввода, закончилась ли генерация и соответствует ли URL выбранному диалогу. Когда всё готово, формирует сообщение протокола:

```text
[WATCHDOG LITE]
MESSAGE_KIND=CONTINUE
COMMAND_ID=cmd-<уникальный идентификатор>
...
WD6_STATUS COMMAND_ID=cmd-<тот же идентификатор> STATE=WORKING
```

Строка `WD6_STATUS` в примере показывает **формат**, а не фактический результат. ChatGPT должен сам выбрать одно из трёх состояний:

| Статус | Поведение Watchdog |
| --- | --- |
| `WORKING` | После проверки ответа отправляет следующую техническую команду. |
| `PASS` | Завершает запуск с успешным результатом; новые сообщения не отправляет. |
| `FAIL` | Завершает запуск как неуспешный; новые сообщения не отправляет. |
| Нет корректного статуса | Пытается уточнить статус (не более двух `REPAIR`), затем останавливается с ошибкой. |

**Карточка диалога:** показывает название вкладки, URL, фазу, число автоматически отправленных сообщений и последнее диагностическое сообщение. **×** останавливает и удаляет *только эту* запись. Кнопка **«Остановить все»** прекращает сопровождение всех записей после подтверждения.

Возможные фазы: **Подготовка**, **Отправка**, **Ожидание ответа**, **Восстановление ответа**, **Завершено**, **Ошибка**. При паузе или ошибке для нового запуска нужно удалить запись и добавить чат снова.

### Что происходит, если ...

- **Я печатаю черновик:** расширение ждёт. Оно не должно стирать текст пользователя, однако при необычных изменениях интерфейса возможны ошибки распознавания — не оставляйте важные черновики без резервной копии.
- **ChatGPT ещё отвечает:** Watchdog ожидает окончания генерации.
- **Вкладка закрыта или открыла другой чат:** отслеживание останавливается с ошибкой. Расширение **не открывает вкладки самостоятельно**.
- **Не обнаружено поле ввода:** выполнение прекращается с ошибкой. **Автоматическая перезагрузка отключена**, чтобы не потерять данные.
- **Произошла неоднозначная отправка:** одно и то же сообщение не посылается повторно вслепую.
- **Нажата кнопка × или «Остановить все»:** удаляется локальное задание. Уже отправленное сообщение ChatGPT или ранее запущенные внешние инструменты это не отменяет.
- **Chrome закрыт, компьютер спит или сеть недоступна:** непрерывная работа не гарантируется; при возвращении проверьте статус вручную.
- **Достигнут лимит 100 сообщений:** Watchdog останавливается. Для нового запуска требуется ручное действие.

## Обновление версии

1. Остановите все отслеживаемые диалоги и отключите старый Watchdog.
2. Сделайте резервную копию папки старой версии (если она нужна).
3. Скачайте новую версию в **отдельную** папку и проверьте `manifest.json`.
4. В `chrome://extensions` удалите старую сборку или укажите папку новой через **«Загрузить распакованное расширение»**. Не считайте состояние заданий автоматически перенесённым: оно зависит от ID расширения и профиля Chrome.
5. Перезагрузите вкладки ChatGPT и добавьте нужные диалоги заново.

Изменение директории распакованного расширения способно привести к изменению его идентификатора Chrome. Не запускайте параллельно дублированные версии.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| Кнопка «Добавить» выдаёт ошибку | Открыт именно чат `/c/...` или `/g/g-...`, а не главная страница. |
| «Диалог уже в списке» | Удалите прежнюю запись через ×, затем добавьте снова. |
| «Ожидание редактора» | Дождитесь загрузки страницы, закончите ввод собственного сообщения, проверьте доступ к отправке. |
| «Отправка не подтверждена» | Посмотрите последнее сообщение непосредственно в чате: повтор вручную может создать дубликат. |
| «Скрипт недоступен» | Перезагрузите вкладку вручную, затем удалите и заново добавьте запись. |
| Нет реакции после обновления ChatGPT | Откройте `chrome://extensions` → **Watchdog Lite** → **Ошибки**; возможна несовместимость DOM-селекторов. |
| Расширение не работает в другом браузере | Поддерживается Google Chrome 120+. Другие Chromium-браузеры отдельно не проверялись. |

Для расследования технических ошибок откройте `chrome://extensions` → **Watchdog Lite** → **Сервис-воркер / Service worker** (DevTools) или DevTools самой вкладки ChatGPT. **Не выкладывайте публично** снимки чатов, токены и полные URL личных переписок.

## Архитектура

```text
Chrome popup (popup.html + popup.css + popup.js)
      │ Только команды управления: ADD / REMOVE / STOP_ALL
      ▼
Service worker (background.js)
      │ chrome.storage.local: состояния без текста переписки
      │ CHECK / PATCH / UPGRADE: проверка отправителя, вкладки и этапа
      ▼
Content script (content.js) — только chatgpt.com
      │ Читает страницу и отправляет технические сообщения через UI
      ▼
Интерфейс ChatGPT (сайт OpenAI)
```

**Хранимые данные:** локальные идентификаторы заданий, URL и названия выбранных диалогов, счётчики, фазы, служебные статусы и диагностические тексты. Полный текст переписок не сохраняется расширением в `chrome.storage.local`, но скрипт читает содержимое видимого чата в оперативной памяти для распознавания статуса. Технические команды, естественно, **передаются самому ChatGPT**, поскольку отправляются через интерфейс сайта.

**Разрешения Chrome:** `storage` (состояние), `alarms` (периодические проверки), `scripting` (подключение сценария к выбранной вкладке), доступ только к `https://chatgpt.com/*`. Нет разрешений на другие сайты, чтение cookies или историю браузера.

Подробная модель угроз и ограничения: [SECURITY.md](SECURITY.md).

## Разработка и локальные тесты

В проекте нет `npm install` и внешних runtime-библиотек. Нужен Node.js 20+ **только для тестов**:

```bash
node --check background.js
node --check content.js
node --check popup.js
node --test tests/*.test.cjs
```

Также включена автоматическая проверка в GitHub Actions. Браузерный end-to-end с реальным интерфейсом ChatGPT этими тестами **не заменяется**: интерфейс сайта может меняться.

